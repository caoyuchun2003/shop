# 邻里小店 · 演示脚本（约 90～120 秒）

用途：录屏给客户看，或自己走一遍确认闭环。

## 准备

| 端 | 地址 / 方式 |
| --- | --- |
| 用户端 H5 | https://shop.yuchuntest.com/ |
| 管理后台 | https://shop.yuchuntest.com/admin/ （令牌 `dev-admin`） |
| 微信壳 | 见 `mp/PREVIEW.md`（开发者工具 / 真机预览） |

口播一句开场：「社区自提轻团购 Demo：下单 → 模拟支付 → 后台核销。支付是演示桩，企业主体到位可换真实微信。」

## 时间轴

| 秒 | 画面 | 操作 / 口播 |
| --- | --- | --- |
| 0～10 | H5 首页 | 划一下商品列表，点「加购」 |
| 10～25 | 购物车 → 结算 | 改数量可选；点「去结算」 |
| 25～45 | 确认订单 | 选自提点，填称呼与手机，提交订单 |
| 45～60 | 订单详情 | 点「模拟支付」，状态变为已支付 |
| 60～90 | 后台订单 | 登录 → 订单列表 →「标为待自提」→「核销完成」 |
| 90～110 |（可选）微信工具 | 打开 `mp` 预览，再走一遍加购，证明小程序壳同源 API |

## 自动化重录（H5 + 后台）

本地起 `8020` / `5173` / `5174` 后：

```bash
cd scripts
env -u VITE_API_URL npm run record-demo
```

产物：`docs/demo/01-h5-order-pay.webm`、`02-admin-fulfill.webm`。  
对外合并版：入口站 `cases/demo/shop-demo.mp4`（案例页可直接播）。

## 收尾一句

「完整业务闭环可演示；真实登录与支付按你的主体资质接入。」
